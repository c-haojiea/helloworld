### 2.1 Markdown 编辑与预览

- 点击文件列表中的 `README.md`，再点右上角**铅笔图标**进入编辑模式。
- 点击 **Preview** 实时查看渲染效果，确保标题、列表、代码块无误。

### 2.2 提交信息（Commit Message）规范

每次保存修改必须填写 Commit Message，例如 `Add installation guide`。
📌 **必背定义**：每个 commit 都是一个不可变的仓库完整快照，由一个 SHA-1 哈希值唯一标识（长 ID 40 位十六进制，短 ID 一般取前 7 位）。
💡 **关键洞察**：通过 commit ID，你可以随时回溯到项目历史中的任何一秒，查看那时的全部文件状态。

### 2.3 查看提交历史

- 在仓库页面顶部点击  **"X commits"** ，查看每次提交的作者、时间、短 ID 和提交信息。
- 点击任意提交 ID 可以进入该时间点的快照视图，所有文件都还原到当时状态。
